# Admin Panel PRD

## Admin modules
Overview, users, subscriptions, entitlements, releases, skills, publishers, developers, support, audit logs, analytics, security events, system configuration.

## User operations
Search by safe identifiers, inspect status, revoke sessions, manage support flags, and initiate approved recovery workflows.

## Billing
Inspect provider/local state, reconcile, and perform privileged refunds only through explicit protected actions.

## Releases
Create draft, upload, verify checksum/signature, stage, publish, revoke. Publication requires elevated permission.

## Skills
Review submissions, inspect manifest/permissions/scan status, approve/reject, revoke.

## Destructive operations
Require target confirmation, reason, step-up auth, permission, and audit event.

## No hidden admin
Admin access is never protected by an unlisted path alone.
