# Skill and Tool Shop PRD

## Discovery
Search, categories, publisher, compatibility, version, permissions, security/review state, changelog.

## Detail page
Show exactly what the skill can access before install. Distinguish required and optional permissions.

## Install
Authorize -> download -> integrity verification -> local installation -> activation.

## Paid skills
Access comes from server entitlement. Client cannot unlock a paid skill by changing local state.

## Reviews
Only show verified/reliable review signals. Never fabricate ratings.

## Moderation
Quarantine submissions until validation/review. Security revocation must propagate to clients.
