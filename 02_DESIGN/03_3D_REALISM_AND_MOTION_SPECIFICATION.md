# OSMOO 3D Realism and Motion Specification

## Hero visual
A dimensional OSMOO core can use layered geometry, light response, subtle particles, and state-driven animation.

## State mapping
Idle = restrained.
Listening = responsive peripheral motion.
Thinking = controlled energy increase.
Acting = directional/transactional motion.
Speaking = synchronized pulse.
Error = restrained warning state.

## Performance budget
Heavy 3D is progressively enhanced. Mobile/low-power devices receive a lighter renderer or static fallback. Effects pause when not visible.

## Accessibility
`prefers-reduced-motion` disables nonessential movement.

## Security
Never load arbitrary remote scripts/textures into privileged surfaces. Visual assets are static, trusted build artifacts.
