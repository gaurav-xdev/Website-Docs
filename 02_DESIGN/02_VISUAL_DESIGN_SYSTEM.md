# OSMOO Visual Design System

## Tokens
Define centralized tokens for color, type, spacing, radius, elevation, opacity, motion, breakpoints, and z-index.

## Components
Button, Link, Navigation, Hero, FeatureGrid, FeatureDetail, PricingCard, Dialog, Drawer, FormField, Toast, Alert, Table, DataGrid, Badge, CodeBlock, Tabs, Breadcrumbs, Pagination, EmptyState, ErrorState, AccountCard, BillingCard, ReleaseCard, SkillCard, AdminActionBar.

## Layering
Public content, application shell, dialogs, notifications, and admin surfaces use a documented z-index scale.

## Typography
Use a limited type scale and avoid tiny text for critical information.

## Dark UI
Do not rely on color alone for status. Pair color with icon/label/state.

## Motion
All motion has purpose and can be disabled.
