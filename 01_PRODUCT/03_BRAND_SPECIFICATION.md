# OSMOO Brand Specification

## Identity
OSMOO is the product. Osmiora is the parent company.

## Voice
Precise, confident, technical, calm, futuristic. Avoid hype without evidence.

## Visual language
Obsidian surfaces, dimensional depth, restrained luminous accents, premium typography, cinematic motion, high information density where appropriate.

## Copy constraints
Never claim human-level intelligence, perfect autonomy, perfect security, guaranteed privacy, or unsupported benchmark superiority.

## Trust language
Explain exactly what is local, what is cloud, what permissions are required, and what data is retained.

## Naming
Public identity must use OSMOO. Legacy VOXY identifiers can remain in internal code only when migration is unnecessary for release correctness.
